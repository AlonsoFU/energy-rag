## GOTCHAS DE INFRA (vigentes)
- **VRAM 8GB es el techo real**: 9b (~6.6GB) + BGE fp16 (~1.16GB) = 7.75GB, margen ~450MB. Con
  contextos muy largos podría rozar OOM — vigilar. Embedder en CPU (barato, 0.2s) para no competir.
- **torch del venv principal (cu130) NO soporta sm_61** → embedder/BGE caen a CPU; solo Ollama usa
  la GPU. Para GPU-torch usar `venv-gpu` (cu118). NO es la GPU ni el modelo, es el build de torch.
- BGE cross-encoder en CPU = lento (un eval de 44q ~20-40min). En GPU fp16 = 0.16s/30 pares.
- Postgres `energy_rag_pg` (Docker, puerto 5434) se cae solo → eval da 0% FALSO. `docker start` + SELECT antes.
- `HF_HUB_OFFLINE=1` obligatorio (cuelgues por API de HF Hub) — ya forzado en `embedder.py`.
- Ollama 9b queda cargado por keep_alive (~5min); `ollama stop qwen3.5:9b` para liberar GPU.
- Waiters: esperar por PID/archivo, NO `pgrep -f "src eval"` (se auto-matchea → deadlock).
- Hay 2 archivos sin commitear ajenos (`queries_diverse.jsonl`, `_rem.jsonl`) — revisar/limpiar.
