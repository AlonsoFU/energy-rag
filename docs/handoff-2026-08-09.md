## 3. Las 3 decisiones abiertas

### 3.1 `think=True` — la métrica decide el veredicto (PRIORITARIA)
Descartado dos veces por `cita_ok` (−17, −16, p=0.0001). Bajo métricas con precisión **gana en
todos los umbrales** (+11 a +40; con "todas las citas correctas": 124 vs 84).
```
prioridad "nunca perder el articulo correcto" -> think=False (hoy).   Pierde precision.
prioridad "no citar normas equivocadas"       -> think=True.          Pierde 16 golds.
```
Es decisión de producto/legal. **Sin probar:** `think=True` + reintento con `think=False` cuando la
respuesta no cita nada válido — recuperaría golds sin reintroducir el ruido.

### 3.2 Caveat de `glossary_inject` — afirma donde debería preguntar
Ante match exacto de término, responde con la definición aunque la query sea vaga:
```
"que es la comision"       -> Comision Nacional de Energia [Art. 5 de 1146553]
"que significa coordinado" -> definicion de "Coordinado"
```
Los términos SÍ están definidos, pero "comisión" también es una tarifa. → item **D4 (UX de
ambigüedad)**: mostrar opciones / preguntar en vez de adivinar.

### 3.3 `D1 vigencia/derogación` — el único error GRAVE que queda
`normas.metadata->>'estado'` vacío (93/95 DESCONOCIDO). El sistema **puede citar norma derogada**.
Es gap de DATOS (scrape BCN), no de código. No necesita GPU. Table-stakes antes de producción.
