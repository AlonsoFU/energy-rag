## Arquitectura actual (pipeline)

```
QUERY → ROUTER (simple/complejo)
  → RETRIEVAL:  BM25 + VECTOR(4B-1024 + alias_union + graph_boost) → RRF → rerank(BGE-GPU) → top-10
  → GATE AND (léxico Y semántico BGE → rechaza off-topic)
  → GEN: qwen3:30b-a3b (temp=0, formato [Art N de NORMA])
  → RESPUESTA + cita
```

**Componentes (todo local, 3090 24GB):**
- embedder: `qwen3-embedding:4b` (Ollama GGUF) truncado MRL a 1024-dim → col `embedding_4b_1024` (HNSW). Flags `embed_4b_dense`+`embed_4b_dim=1024`.
- alias map: `src/pipelines/alias_map.py` (curado, query-side, determinista) + `alias_union` (unión RRF query original + query-con-término-legal, rerank alias-aware).
- reranker: `bge-reranker-v2-m3` en GPU (`BGE_DEVICE=cuda`; antes forzado a CPU por Pascal).
- gate: off-topic `AND` (léxico + BGE score).
- gen: `qwen3:30b-a3b` (`.env` LLM_DEFAULT=ollama/qwen3:30b-a3b).

1. **Verificación 3090:** torch cuda OK; BGE reranker GPU 0.13s/32pares (antes ~20-30min/eval CPU); 8B embedder cabe. Restricciones Pascal (BGE-CPU, sin fp16, swap 4B↔9B, "no cabe") OBSOLETAS.
2. **alias_union (Exp #2)** — vocabulario controlado coloquial→legal query-side, sin escribir DB. Diseño 3-piezas: unión RRF + rerank alias-aware + alias bien curado. Gen: coloquial 32→35 (+3), dev/holdout sin regresión. Rescató 87/118/212 a retrieval. `exp_alias_screen.py`, `exp_alias_gen.py`.

4. **Embedder 8B vs 4B (gen completo):** 8B = TRADE-OFF (dev +5, coloquial −4). 4B queda campeón coloquial. `exp_8b_gen.py`, flag `embed_8b_dense` + `vectorstore.search_vector_8b`.

## Cómo correr evals (GOTCHA post-reboot, CRÍTICO)

El env heredado rompe HF offline aunque HF_HOME esté seteado. Usar env limpio:

```bash
# wrapper: logs/run_verify.sh
setsid env -i HOME=/home/alonso PATH=/usr/local/bin:/usr/bin:/bin \
  HF_HOME=/home/alonso/datos/hf HF_HUB_CACHE=/home/alonso/datos/hf/hub \
  TRANSFORMERS_CACHE=/home/alonso/datos/hf/hub HF_HUB_OFFLINE=1 \
  BGE_DEVICE=cuda PYTHONPATH=. \
  venv/bin/python -m scripts.<script> > logs/<script>.log 2>&1 < /dev/null &
```

- `setsid` + log al dir del proyecto: la sesión Claude se reinicia, borra `/tmp` y mata procs no-detached.
- Modelos (Ollama + HF) viven en `/home/alonso/datos`, NO en root.
- Postgres `energy_rag_pg` (Docker :5434) se apaga solo → `docker start energy_rag_pg`.
- Scripts de eval guardan `result.json` tras cada corrida (sobrevive muertes).
- 30b-a3b: ~35s/query (MoE). Un eval de 101 queries × 1 gen ≈ 60min.
